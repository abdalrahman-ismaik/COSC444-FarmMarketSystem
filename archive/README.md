# Preserved reference materials

This directory retains original inputs. It is not an alternative application entry point.

- `original-package/FarmMarketSystem_Team.zip`: original application ZIP, preserved unchanged.
- `original-package/README.md`: README from the ZIP, retained as historical evidence; its original relative paths refer to the old package layout.
- `lab-example/application.py`, `schema.sql`, `data.sql`: school-enrollment natural-language SQL lab example, separate from the farm project. The example contains a hardcoded sample password default; do not treat it as a real credential or deploy it.

Use the [root README](../README.md) and maintained `app/` directory. The original application/SQL/images can be compared byte-for-byte with ZIP members; results and the original-file inventory are in the [repository review](../docs/REPOSITORY_REVIEW.md).
